# 聊天对话界面设计规范（智能体统一接入 · UI 设计输入）

- 版本: v1.0（2026-11-03）
- 性质: 智能体统一接入特性（独立立项）的 **UI 设计规范**；立项时直接引用本文档
- 参考: ChatGPT / DeepSeek / Claude 的成熟对话模式 + macOS HIG（.zcode/skills/macos-hig）
- 关联: doc/requirements-ui-refactor.md 第 5 节、doc/requirements-remote-access.md、src/lib/bridge（agent:* 帧协议已预留）、doc/功能点清单.md B3/B4/I3

## 1. 定位与架构决策

- 聊天视图是**内容区的一个视图**（挂载于 WindowFrame 的 children 插槽，挂载点已预留 `src/components/chat/`），**不是独立窗口/独立应用**
- 聊天会话**复用现有会话体系**（appStore + session 表，toolType=claude/codex/gemini/opencode），侧栏项目树不另起炉灶——聊天只是同一会话的**新展示形态**
- 与终端的关系（B3 决策）：同一会话**默认聊天视图**，终端视图保留为可切换的高级模式（视图切换控件在聊天区右上角，图标切换，非全局设置）
- 通道：Rust `AgentBackend` 工厂（独立立项交付）→ `agent:message` / `agent:state` 事件 → 前端流式渲染

## 2. 布局结构

### 桌面（≥768px）

```
┌──────────────────────────────────────────────┐
│ TitleBar（现有骨架，不变）                      │
├────────┬─────────────────────────────────────┤
│ 侧栏    │  聊天区                              │
│ (现有   │  ┌─────────────────────────────────┐│
│ 项目树  │  │ 消息流（唯一滚动区，自动跟随底部）  ││
│ 复用，  │  │  [日期分隔线]                     ││
│ 不另做  │  │  [用户气泡]        [AI 消息全宽]  ││
│ 会话    │  │  [工具调用折叠卡片]               ││
│ 列表]   │  └─────────────────────────────────┘│
│        │  ┌─────────────────────────────────┐│
│        │  │ 输入区（底部固定，多行自适应）       ││
│        │  └─────────────────────────────────┘│
├────────┴─────────────────────────────────────┤
│ StatusBar（现有骨架，不变）                     │
└──────────────────────────────────────────────┘
```

- 消息流是**唯一滚动区**；输入区吸底固定；侧栏复用现有（不新增会话列表 UI）
- 内容区内边距：消息流水平居中，最大宽度 **720px**（长文本可读性基准，ChatGPT/DeepSeek 同款）

### 移动端（<768px）

- 侧栏走现有抽屉模式（T17）；消息流全宽（max-width 100%，左右 12px 边距）
- 输入区吸底并适配安全区（`env(safe-area-inset-bottom)`）
- 输入区上方弹出软键盘时消息流自动滚底（visualViewport 监听）

## 3. 消息形态（非对称设计，ChatGPT/DeepSeek 风格）

| 角色 | 形态 | 说明 |
| --- | --- | --- |
| **用户消息** | 右对齐**气泡**：`--primary` 背景 10% 透明 + `--primary` 文字，圆角 12px（右上角 4px 收角），max-width 75% | 自己的内容用气泡包裹，与 AI 区分 |
| **AI 消息** | **无气泡全宽**左对齐：头部 `[工具图标 14px] [工具名 caption]`，正文直接 Markdown 排版 | AI 回答长且含代码块，气泡妨碍阅读——ChatGPT/DeepSeek/Claude 共同的现代模式 |
| **工具调用** | **折叠卡片**：`▸ [工具图标] 工具名 + 参数摘要 …… [状态]`，圆角 8px `--card` 底、1px `--border` | TeaCoder 特有：Claude Code 的 tool_use 链；默认折叠，点击展开参数/结果详情 |
| **错误** | `--destructive` 左边条 3px + 浅红底的卡片，含错误文案与 [重试] 按钮 | 对应 agent 帧的 `kind: "error"` |

- 头像：AI 消息仅头部小图标（lucide 对应工具图标）+ 工具名 caption；用户消息无头像
- 时间戳：不常驻；日期分隔线（`— 11月3日 —` 居中小字）按天分组；单条时间 hover 气泡显示

## 4. 流式渲染（agent:message 驱动）

- **打字机式追加**：text 块按 seq 顺序追加渲染，滚动自动跟随底部（用户上滚超过 48px 即暂停跟随，出现"↓ 回到底部"浮动按钮）
- **流式中输入区变形**：发送按钮 → **停止按钮**（方块图标，`--destructive`）；点击停止 = 中断生成，保留已生成内容 + 消息尾部 [继续] 按钮
- AI 消息尾部 hover 工具条：`[复制] [重新生成]`（ghost 图标钮，12px 间距）
- 光标：流式中文末尾显示 2px 竖线闪烁光标（`--primary`）

## 5. Markdown 与代码块

- 渲染管线**复用现有** `transcript/MarkdownBody`（react-markdown + remark-gfm + rehype-sanitize + 代码高亮），抽为共享组件（`src/components/markdown/`），transcript 与聊天共用——不复制两份
- 代码块样式：`--card` 深底圆角 8px、头部 `[语言名 …… 复制按钮]`、横向滚动、行高 1.6
- 表格/列表/引用/行内代码样式按 GFM 默认 + 语义 token 着色；链接 `--primary` 且外链新窗口

## 6. 输入区

- **多行自适应**：1 行起，最多 8 行（超出内部滚动）；高度变化用 transition 100ms
- **发送**：Enter 发送 / Shift+Enter 换行（输入法组合中 Enter 不发送——`isComposing` 判断）
- 发送按钮：右下角圆形 28px，`--primary` 底白色上箭头；空输入禁用态 40% 透明
- **Esc = 停止生成**（流式中）；⌘↑ = 编辑上一条用户消息（内容回填输入框）
- 占位文案 i18n：`chat.inputPlaceholder`（"给智能体发送消息…" / "Message the agent…"）
- 失败处理：发送失败的用户的气泡标红左边条 + [重试]
- 增强项（V3，不做入 MVP）：@文件路径补全、/ 斜杠命令面板（映射 CLI slash 命令）、图片粘贴

## 7. 会话状态（对齐 AgentSessionState）

| 状态 | UI 表现 |
| --- | --- |
| `idle` | 正常输入；空会话显示空态：居中图标 + "开始新对话" + 3 个示例问题卡片（点击即填入输入框） |
| `thinking` | AI 消息头部"思考中…" + 三点脉冲动画；输入区照常可输入（排队） |
| `waiting_input` | AI 停止等待用户决策：输入框顶部出现黄色提示条（"智能体等待你的输入"），输入框 `--ring` 高亮 |
| `error` | 错误卡片 + [重试]；toast 提示（sonner） |

## 8. 动效（沿用 macos-hig 第 6 章，补充对话特有）

| 动效 | 参数 |
| --- | --- |
| 消息入场上滑淡入 | 200ms ease-out，仅新消息触发，不作用于历史 |
| 流式滚动跟随 | 逐帧贴底（rAF），用户上滚即让位 |
| 思考中三点脉冲 | 1.2s 循环，三点相位错开 200ms |
| 折叠卡片展开 | 高度过渡 150ms + 箭头旋转 90° |
| `prefers-reduced-motion` | 全部降级为 ≤100ms 淡入淡出（红线） |

## 9. 键盘与可达性（macos-hig 第 7 章全量适用，补充）

- 消息流区域可 Tab 遍历：代码块复制钮、折叠卡片、消息工具条
- AI 消息工具条与折叠卡片需 aria-label（i18n）
- 屏幕阅读器：AI 消息容器 `aria-live="polite"`（流式更新朗读不打断）

## 10. 分期（智能体立项时的实施建议）

| 阶段 | 范围 |
| --- | --- |
| **MVP** | 单会话消息流 + 非对称消息形态 + 流式渲染 + Markdown/代码块 + 输入区（发送/停止/Esc）+ 空态 + 三会话状态 |
| **V2** | 工具调用折叠卡片、复制/重新生成工具条、日期分隔线、错误重试、thinking/waiting_input 完整态 |
| **V3（增强）** | @文件引用、斜杠命令面板、图片粘贴、拖出会话为独立窗口、终端/聊天视图切换的会话内共存（同屏双视图） |

## 11. 明确不做（边界）

- 不做 AI 消息气泡（与 ChatGPT/DeepSeek 反模式结论一致）
- 不做会话列表独立 UI（复用项目树侧栏）
- 不做多模态语音输入、AI 语音朗读（远期评估）
- 不在本规范内定义 Rust AgentBackend 工厂（属独立立项需求文档，本文件只消费其帧协议）
