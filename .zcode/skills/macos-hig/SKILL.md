# macOS HIG 设计规范（TeaCoder 落地版）

> 依据：Apple Human Interface Guidelines 官方文档 + WWDC17/WWDC20 会话。
> Apple 不公开全部精确数值，文中标注 ≈ 的为社区实测共识值；其余为 HIG 明确指引。

## 1. 三大设计原则（一切判断的源头）

| 原则 | 含义 | TeaCoder 落地 |
| --- | --- | --- |
| **Clarity（清晰）** | 文字清晰易读、图标精确、装饰克制；内容优先于装饰 | 不为好看加渐变/重投影；终端内容区永远最高对比、零毛玻璃 |
| **Deference（内容优先）** | UI 帮助理解内容，永不与内容竞争 | 毛玻璃只用于"壳"（标题栏/侧栏/状态条），内容区实色；色彩克制，蓝仅表交互 |
| **Depth（层次纵深）** | 视觉层次与真实动效表达层级关系 | 弹窗浮于毛玻璃之上、卡片浮于背景之上；浮层带投影，层级越高投影越大 |

判断口诀：**壳可以虚，内容必须实；装饰可以有，不能抢内容。**

## 2. 度量基准（px，@1x）

### 窗口与标题栏
- 标题栏三档：**28**（纯标题）/ **38**（紧凑工具栏 unifiedCompact）/ **52**（完整工具栏 unified）
- TeaCoder 取 **38px**：工具型应用、信息密度优先
- 交通灯：直径 **12px**、中心间距 **20px**（视觉 gap 8px）、距左边缘 **12~20px**；hover 才浮现符号
- 窗口圆角 **10px**；非激活窗口整体降饱和（可简化为标题文字降透明度）

### 侧栏
- 宽度：**≈200~240px**（Finder 档位；TeaCoder 取 200）
- 行高：**28px**（紧凑）/ **37px**（宽松）；TeaCoder 取 28
- 行样式：圆角高亮块（左右留边 ~8px），选中用 `--accent`，非选中 hover 半透明 accent
- 分组标题：**11px** 大写或常规，`--muted-foreground`，与内容弱对比

### 状态条
- 高度 **≈24~28px**、字号 **11px**；TeaCoder 取 28px

### 控件
- 常规控件高度：**小 20 / 中 28 / 大 32px**；表单与按钮默认 **28px**（中号）
- 控件圆角：**6px**（小件）/ **8px**（中件）；连续圆角感由 token `--radius` 统一驱动
- 焦点环：**双环**（外白内蓝，2px ring + offset），键盘可达性强制要求

### 按钮（HIG 档位，`ui/Button` 已对齐）
- 尺寸档：**default 28px / sm 24px / xs 20px / lg 32px**；图标钮同步（icon 28 / icon-sm 24 / icon-xs 20 / icon-lg 32）
- 变体语义（强制）：
  - `default` = **主要动作**：accent 蓝填充白字 + 微投影；一个视图内主要动作唯一
  - `outline` = **标准 push button**：实色底（card）+ 细边框 + 低投影，hover 淡 accent——macOS 里大多数按钮长这样
  - `ghost` = 工具栏/行内图标钮；`destructive` = 破坏性动作红
- 交互反馈：hover 背景微变；**按下 `scale(0.98)` + 亮度微降**（link 豁免）；过渡 100~150ms

### 设置卡片分组（Ventura 风格，`settings/next/SettingsSection` 已封装）
- 一组设置 = **标题在卡片外**（13px medium、非大写、`--foreground/90`）+ **圆角色块卡**（`rounded-xl border-border/40 bg-card`，bg-card 在 bg-background 上形成色块分层）
- 卡内行间 **hairline** 分割（`divide-border/40`）；行样式 `px-4 py-2.5`、行高基准 36px
- 禁止裸行 + 分割线的散排（旧观感）；窄屏（<768px）行内 label/控件改上下堆叠

### 滚动条（全局统一）
- **8px 槽位 / 4px 视觉宽**圆角细条（`border 2px transparent + background-clip: padding-box`）
- 滑条色：`muted-foreground` 35%（hover 60%），轨道透明——跟随明暗主题
- 双语法：`::-webkit-scrollbar` + `scrollbar-width/color`（Firefox）；终端 xterm 滚动条对齐同观感
- 例外：TabBar 滚动条隐藏（右缘渐隐提示）；定义唯一落在 `src/index.css` 全局段

## 3. 排版（SF 字体体系）

- 字体栈：`system-ui → SF Pro（苹果端自动）→ PingFang SC → Microsoft YaHei → Noto Sans CJK SC`
- 光学变体：<20px 用 SF Pro Text，≥20px 用 SF Pro Display（系统字体自动切换，无需干预）
- 字号阶梯（macOS 桌面档位，HIG 最小可读 **11px**）：

| 层级 | px | 字重 | 用途 |
| --- | --- | --- | --- |
| Caption | **11** | regular / medium | 状态条、分组标题、辅助说明 |
| Body（默认） | **13** | regular | 正文、列表行、控件文字 |
| Emphasized | **13** | medium/semibold | 强调行、窗口标题、选中态 |
| Title | **15** | semibold | 页面标题、空态主文案 |
| Large Title | **≥20** | bold | 面板大标题（少用） |

- 规则：**一个界面不超过 3 个字号层级**；中文不强制 SF（回退栈接管），但字阶不变

## 4. 颜色系统（macOS 系统色，浅色 / 深色）

| 语义 | 浅色 | 深色 | TeaCoder 用途 |
| --- | --- | --- | --- |
| systemBlue | `#007AFF` | `#0A84FF` | `--primary`：一切可交互指示 |
| systemRed | `#FF3B30` | `#FF453A` | `--destructive`：删除/关闭/危险 |
| systemGreen | `#28C840`* | `#28C840`* | 成功状态、运行中指示 |
| 窗口背景 | `#F5F5F7` | `#1E1E20` | `--background` |
| 卡片 | `#FFFFFF` | `#28282B` | `--card` |
| 分隔线 | `#D9D9DE` | `#38383C` | `--border` |
| 次级文字 | `#6E6E73` | `#98989D` | `--muted-foreground` |

\* macOS 绿灯专用绿（systemGreen 常规值为 `#34C759`/`#30D158`，交通灯用其专属变体 `#28C840`）
规则：**蓝色只给交互元素**；状态色（绿=正常/红=错误）不与交互蓝混用；明暗双套必须同步定义。

## 5. 材质与层次（毛玻璃的正宗用法）

- **Vibrancy/毛玻璃只用于"容器壳"**：标题栏、侧栏、浮层底部；内容区（终端/编辑器/列表）禁止
- 配方：半透明底（背景色 70~80% 不透明度）+ `backdrop-blur`（24~40px）+ 饱和度提升 `saturate(1.4)`
- 层级与投影（Depth 原则）：
  - 窗口本体：大投影（`0 24px 80px / 45%`）
  - 卡片：`0 1px 3px / 8%` 级别的低扩散小投影
  - 浮层（菜单/弹窗）：介于两者之间，且必须有 1px 描边
- 深色模式下毛玻璃底色要**更深而不是更透**，避免内容透字

## 6. 动效

- 时长：微交互（hover/按下）**100~150ms**；弹出/展开 **200~250ms**；转场 ≤300ms
- 缓动：进出用标准 ease（`cubic-bezier(0.25, 0.1, 0.25, 1)`）；弹层用轻微减速（`cubic-bezier(0.2, 0.8, 0.2, 1)`）
- 惯例：hover 是背景色变化（不用位移）；按下可微缩放 `scale(0.98)`；禁用弹跳/回弹过量
- 尊重 `prefers-reduced-motion`：动效降级为淡入淡出

## 7. 交互设计原则（与视觉同等强制）

> 用户要求：UI 交互必须遵守 macOS 设计语言，不只是外观。以下为交互层强制规范。

### 7.1 键盘可达性（HIG 核心要求）

- 所有可交互元素**必须**可 Tab 聚焦，焦点顺序与视觉/逻辑顺序一致
- 焦点环永不移除（`outline: none` 禁止）；shadcn `Ring` 样式为准（双环：外环 offset + 内环）
- 快捷键遵循 macOS 惯例：⌘C/⌘V/⌘X/⌘A、⌘W（关标签）、⌘T（新标签）、⌘F（搜索）、⌘,（设置）、Esc（关闭弹层/退出编辑）
- **平台修饰键显示规范（强制）**：修饰键符号按运行平台显示，禁止硬编码 "⌘"/"Ctrl" 字面量——macOS 显示 ⌘⌥⇧⌃；Windows/Linux 显示 Ctrl/Alt/⇧。实现统一经 `formatShortcut(keys)`（`src/lib/shortcut.ts`，快捷键总表见 doc/design-ui-patterns.md 第 3 章），菜单右列、设置页、Tooltip 全部走它
- 展示快捷键：macOS 用符号（⌘⌥⇧⌃），Windows/Linux 用文字键名（Ctrl/Alt/Shift）
- 弹窗/菜单打开时**焦点陷阱**（focus trap），关闭后焦点回到触发元素

### 7.2 指针与触控交互

- hover 只做背景色微变（accent），禁止 hover 位移/缩放（桌面端）
- 按下态：`scale(0.98)` + 亮度微降，150ms 内完成
- 命中区域：小控件（交通灯级 12px）外扩热区至 ≥20px；触屏场景遵循 44×44px 最小命中
- 移动端（web-remote）：点击无 hover 残留、滑动手势用于抽屉/列表操作、双击缩放禁用（viewport 控制）

### 7.3 拖拽与排序

- 拖拽源半透明（opacity 0.6）+ 有效目标区高亮；放置前显示插入位置指示线
- 拖拽过程禁用文本选择（`user-select: none`）
- 折叠面板、分割条拖拽实时反馈，松手才持久化

### 7.4 弹层与菜单行为

- 右键菜单一律 DropdownMenu（受控），禁止浏览器原生菜单
- 弹层关闭方式三种齐备：Esc 键 / 点击外部 / 明确关闭按钮
- Popover 依赖触发元素定位，滚动跟随；层叠顺序：菜单 < 弹窗 < 拖拽提示
- 嵌套弹层只允许一层（菜单内不再弹菜单，改用子菜单 submenu）

### 7.5 破坏性操作与防误触

- 删除/清空类操作必须 AlertDialog 二次确认，确认按钮用 `--destructive` 红字放右侧
- 列表行内删除：先 Popover 确认或滑动露出删除（移动端），禁止直接删
- 表单提交按钮在必填项未完成时禁用（而非点击后报错）

### 7.6 状态反馈

- 加载中：局部 spinner（<300ms 的等待不显示，避免闪烁）
- 空态：图标 + 一句话 + 可选动作按钮，居中，muted 色阶
- 成功/失败：sonner toast；失败 toast 必须含可操作信息（重试按钮或原因）
- 长任务（文件传输类）：进度条 + 可取消

### 7.7 系统偏好尊重

- `prefers-reduced-motion: reduce` 时全部动效降级为淡入淡出（≤100ms）
- `prefers-contrast: more` 时提升文字与边框对比（后续高对比度主题挂钩）
- 窗口失焦（blur）时标题栏与交通灯降饱和（macOS 未激活态惯例）

### 7.8 原有惯例（保留）

- **交通灯**：hover 整组浮现符号；符号为对应深色调（×深红 / −深棕黄 / ◤◢实心三角深绿）
- **拖拽区域**：标题栏空白区整条可拖窗（`data-tauri-drag-region`），交互控件除外
- **快捷键**：遵循 macOS 惯例（⌘C/⌘V/⌘W/⌘T…），设置页用 ⌘ 符号而非 Ctrl 文案

## 8. 标签页规范（TabBar 强制基线）

> 现状教训：旧实现 `flex-wrap` 换行堆叠 + 固定宽度，导致布局跳动、空间浪费——macOS 正统做法是**单行弹性收缩**。

### 8.1 布局与尺寸

- **单行铁律**：标签永不换行；空间不足时收缩宽度，而非折行
- 标签栏紧贴标题栏下沿，与工具栏**融合**（延续毛玻璃 `surface-blur`，非独立色块）
- **弹性宽度**（Safari 式）：所有标签 `flex: 1` 均分可用空间；active 标签允许略宽（1.2 倍权重）
- 尺寸约束：min **96px** / max **200px**；高度 **32px**（比控件行高略高，触达舒适）
- 新建按钮：标签栏末端常驻 **+**（ghost 样式），双击标签栏空白区等效

### 8.2 标签内容与状态

- 内容结构：`[状态点 6px] [图标 14px] [标题 truncate] [关闭 ×]`
- 状态点语义：运行中=绿色脉冲（`running-dot`）/ 有未读输出=蓝色静态 / 错误=红色
- 关闭按钮 **hover 才显示**（仅 active 标签与被 hover 标签渲染 ×；非 active 常驻隐藏——与 Chrome 常驻 × 相区别，这是 macOS 惯例）
- active 标签：字重 medium + 前景满色 + 背景与内容区对齐（视觉上标签"打开"向内容）；非 active：`foreground/70`

### 8.3 溢出策略（空间不足时依序降级）

1. 全体标签等比收缩至 min 宽度
2. 标签栏**横向滚动**（滚轮横滚 / Shift+滚轮 / 触控板手势），右缘 8px 渐隐遮罩提示可滚
3. （可选增强）`»` 溢出列表菜单，列出全部标签

### 8.4 交互行为

- **拖拽重排**：按下即拖（150ms 长按阈值防误触）；被拖标签抬起（scale 1.05 + 阴影），其余标签**位移动画**让位；插入位置显示 2px 指示线；`user-select: none` 全程
- 拖出标签栏：桌面端可脱离成新窗口（Tauri 可实现，列为增强项，不强制首版）
- **中键点击 = 关闭**；**双击 = 重命名**（inline 编辑，Esc/失焦提交）；右键菜单：关闭 / 关闭其他 / 关闭全部
- 移动端（web-remote）：长按 = 上下文菜单；无 hover → 关闭按钮在 active 标签常驻显示

### 8.5 键盘与焦点

- ⌘T 新建 / ⌘W 关闭当前 / ⌘1~9 直达 / ⌘⇧[ ⌘⇧] 前后切换（触控板三指左右滑同义）
- 关闭当前标签后焦点移至**右邻**（右邻不存在则左邻）
- 恢复刚关闭的标签：⌘⇧T（需要 store 支持 tab 历史栈，列为增强项）

## 9. 检查清单
