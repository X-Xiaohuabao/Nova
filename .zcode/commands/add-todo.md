# /add-todo - 快速添加待办事项

作为待办事项管理助手，帮我快速添加待办任务。支持自动创建缺失文档、联动项目状态。

---

## 使用方式

```
/add-todo 实现 SSH 会话的录制回放
/add-todo 修复 Windows 下分屏闪烁，优先级高
/add-todo 优化 JSONL 解析性能，3天，中等优先级
/add-todo cost 实现 Gemini 费用适配
```

---

## 第一步：智能检测文档状态

### 检查 doc/待办清单.md

如果 `doc/待办清单.md` 不存在：
1. 读取模板 `.zcode/templates/待办清单模板.md`
2. 替换时间占位符为当前时间
3. 创建 `doc/待办清单.md`
4. 输出提示：`📝 已自动创建 doc/待办清单.md`

---

## 第二步：解析任务信息

### 从用户输入中提取

| 信息 | 解析方式 | 默认值 |
|------|---------|--------|
| 任务名称 | 必填，主体内容 | - |
| 优先级 | "高"/"中"/"低"，或"紧急"/"重要" | 中 |
| 预计时间 | "X天"/"X周" | 待定 |
| 所属模块 | 模块名前缀如"pty"、"cost"、"settings"、"终端UI" | 通用 |
| 截止日期 | "截止XX"或"deadline XX" | 待定 |

### Nova 有效模块名

`pty` / `cli` / `profile` / `cost` / `storage` / `session` / `ssh` / `crypto` / `llm_provider` / `tool_settings` / `终端UI` / `设置` / `会话管理` / `通用`

---

## 第三步：写入待办清单

按优先级插入 `doc/待办清单.md` 对应区域，格式：

```markdown
- [ ] {任务名称}
  - 描述: {一句话说明}
  - 所属模块: {模块名}
  - 预计工作量: {天数}
  - 添加时间: {YYYY-MM-DD HH:MM}
```

规则：
- 动词开头的短语，不超过 15 字
- 高优先级任务如有截止日期必须标注
- 更新文档头部「最后更新」时间

---

## 第四步：联动更新（轻量）

- 若 `doc/项目状态.md` 存在且「下一步计划」为空或明显过时 → 用本次新增的高优先级任务提示刷新建议（不自动改写，输出建议让用户确认）
- 若任务来自某个活跃台账的遗漏 → 提示是否同步登记到 `doc/tasks/active/` 对应文件

## 输出格式

```
✅ 已添加待办：{任务名称}
   优先级：{高/中/低} | 模块：{模块名}
   当前高优先级待办：{N} 项
```
