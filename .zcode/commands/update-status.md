# /update-status - 智能更新项目状态

作为项目状态更新助手，智能更新项目管理文档。支持自动创建缺失文档、联动更新三个文档。

---

## 第一步：智能检测文档状态

### 1.1 检查三个核心文档

检查 `doc/` 目录下是否存在以下文件：
- `doc/项目状态.md`
- `doc/待办清单.md`
- `doc/requirements.md`

缺失的处理：
- `项目状态.md` 缺失 → 用模板 `.zcode/templates/项目状态模板.md` 创建，占位符按扫描结果填充
- `待办清单.md` 缺失 → 用模板 `.zcode/templates/待办清单模板.md` 创建
- `requirements.md` 缺失 → 提示走 `/kickoff`，不自动生成

### 1.2 收集真实数据（并行执行）

```bash
git log -20 --format="%H|%s" --no-merges          # 最近提交
ls doc/tasks/active/                               # 活跃台账
ls doc/tasks/done/ 2>/dev/null                     # 已归档台账
```

对每个活跃台账统计 `[x]` / `[ ]` 数量与最近更新时间；对最近提交按模块归类。

---

## 第二步：更新 doc/项目状态.md

逐节更新（只改有变化的部分，保留人工写的内容）：

| 章节 | 数据来源 |
|------|---------|
| 当前状态（阶段/进度/重点/下一步） | 台账完成率 + 最近提交方向综合判断 |
| 模块概览表 | 按 TeaCoder 模块（pty/profile/cost/storage/终端UI/设置/会话/SSH）汇总 |
| 已完成 | 最近勾完的台账项 + 对应提交 hash |
| 进行中 | 活跃台账的未勾项 |
| 问题和风险 | 停滞任务、自检不过项、架构隐患 |

更新头部「最后更新」。

---

## 第三步：联动刷新 doc/待办清单.md

1. 台账中已完成但待办清单仍有的项 → 勾选 `[x]`
2. 台账新增的未勾项 → 按优先级补录
3. 冲突时以台账（task-tracker）为准，差异列出让用户确认

---

## 第四步：输出更新摘要

```
✅ 项目状态已更新（YYYY-MM-DD HH:MM）

📊 快照：
- 活跃特性：{N} 个（{特性名 x 完成率}）
- 本期完成：{N} 项 / 新增待办：{M} 项
- 风险：{有则一句话，无则"无"}

修改的文件：
- doc/项目状态.md（当前状态、模块概览）
- doc/待办清单.md（勾选 2 项、补录 1 项）
```

## 约束

- **只依据真实数据**：进度百分比来自台账勾选统计，不拍脑袋
- **不覆盖人工内容**：用户手写的备注、风险描述保留原样
- **不动需求文档**：需求变更走 `/kickoff` 的人工门
